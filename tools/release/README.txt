Warcraft Survivors - test build
===============================

You need Warcraft III version 1.29 ("Legacy", the old MPQ install with War3.mpq
and War3x.mpq). Reforged does not work. The game files are read from your
install; nothing of Blizzard's is included here.

1. Run "Play Warcraft Survivors.bat".
2. If Warcraft III is not in C:\Program Files (x86)\Warcraft III (Legacy),
   pick its folder once (the one with War3x.mpq). It is remembered.

The game opens borderless over the whole screen; Alt+Tab works.
Escape opens the menu (options, key bindings, quit).
Your progress is saved in %APPDATA%\warcraft-3\CustomMapData\WarcraftSurvivors\.
